# IT Asset Register

ระบบทะเบียนอุปกรณ์ไอที — เว็บแอปไฟล์เดียวสำหรับบันทึกและติดตามอุปกรณ์ไอทีขององค์กร (โน้ตบุ๊ก จอ เครื่องพิมพ์ สวิตช์ กล้องวงจรปิด ฯลฯ)

## แก้ปัญหาอะไร

ทีมไอทีที่ดูแลอุปกรณ์หลายร้อยเครื่องมักเจอปัญหาการบันทึกข้อมูลด้วยไฟล์ Excel ที่ส่งต่อกันทางอีเมล ทำให้หาข้อมูลไม่เจอ ไม่รู้ว่าเครื่องไหนอยู่กับใคร และมีหลายเวอร์ชันของไฟล์จนสับสนว่าอันไหนล่าสุด โปรเจคนี้รวมข้อมูลอุปกรณ์ทั้งหมดไว้ในที่เดียว ค้นหาได้ง่าย และติดตามประวัติการย้าย/เปลี่ยนผู้ถือครองได้ โดยไม่ต้องพึ่งเซิร์ฟเวอร์หรือฐานข้อมูลใด ๆ

## ฟีเจอร์

- เพิ่ม / แก้ไข / ลบ ข้อมูลอุปกรณ์
- ค้นหาและกรองอุปกรณ์ตามผู้ถือครอง / ประเภท / สถานะ
- นำเข้าข้อมูลจากไฟล์ Excel/CSV เดิม
- บันทึกข้อมูลอัตโนมัติในเบราว์เซอร์
- ส่งออกข้อมูลเป็นไฟล์ CSV/Excel เพื่อสำรองข้อมูล
- บันทึกประวัติการย้าย/เปลี่ยนผู้ถือครองของอุปกรณ์แต่ละชิ้น
- แท็กสถานะอุปกรณ์ (ใช้งาน / ซ่อม / เลิกใช้ / สำรอง)
- แจ้งเตือนเมื่อใกล้หมดประกันหรือไม่มีการอัปเดตนาน

## วิธีเปิดใช้งาน

1. ดาวน์โหลดหรือ clone repository นี้
2. เปิดไฟล์ `index.html` ด้วยเบราว์เซอร์ (ดับเบิลคลิกได้เลย ไม่ต้องติดตั้งอะไรเพิ่ม)
3. ถ้ามีข้อมูลอุปกรณ์เดิมในไฟล์ Excel/CSV ให้ใช้ปุ่ม "นำเข้าข้อมูล" เพื่อนำเข้าเป็นข้อมูลตั้งต้น
4. ข้อมูลจะถูกบันทึกอัตโนมัติในเบราว์เซอร์ที่ใช้งาน แนะนำให้กด "ส่งออกข้อมูล" เป็นระยะเพื่อสำรองไฟล์ไว้

> หมายเหตุ: ระบบใช้งานได้จากเครื่องเดียวเท่านั้น หากเปลี่ยนเครื่องหรือล้าง cache เบราว์เซอร์ ต้องนำไฟล์ที่สำรองไว้กลับมานำเข้าใหม่

## เทคโนโลยีที่ใช้

- HTML / CSS / JavaScript (ไฟล์เดียว ไม่มี build tool)
- localStorage สำหรับเก็บข้อมูลในเบราว์เซอร์
- SheetJS (xlsx) สำหรับอ่าน/เขียนไฟล์ Excel
