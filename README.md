# IT Asset Register

ระบบทะเบียนอุปกรณ์ไอที — เว็บแอปไฟล์เดียวสำหรับบันทึก ค้นหา และจัดการข้อมูลอุปกรณ์ไอที (โน้ตบุ๊ก จอ เครื่องพิมพ์ สวิตช์ กล้องวงจรปิด) โดยไม่ต้องใช้เซิร์ฟเวอร์หรือฐานข้อมูล
เหมาะสำหรับผู้ดูแลระบบไอทีคนเดียวที่ต้องการเลิกใช้ไฟล์ Excel ที่ส่งต่อกันจนสับสนว่าอันไหนล่าสุด

## ฟีเจอร์

- เพิ่มข้อมูลอุปกรณ์ใหม่ (ชื่ออุปกรณ์ ประเภท หมายเลขเครื่อง ผู้ถือครอง สถานะ)
- แก้ไขข้อมูลอุปกรณ์ที่มีอยู่แล้ว
- ลบข้อมูลอุปกรณ์ พร้อมกล่องยืนยันก่อนลบทุกครั้ง
- ค้นหาอุปกรณ์แบบเรียลไทม์ (พิมพ์แล้วกรองทันที) จากชื่ออุปกรณ์ หมายเลขเครื่อง หรือผู้ถือครอง โดยไม่สนตัวพิมพ์เล็ก-ใหญ่
- กรองรายการตามประเภทอุปกรณ์และสถานะ
- แสดงจำนวนรายการที่พบเทียบกับทั้งหมด (เช่น "พบ 5 จาก 12 รายการ")
- แจ้งข้อความเมื่อค้นหาแล้วไม่พบข้อมูล แทนที่จะแสดงตารางว่างเปล่า
- บันทึกข้อมูลอัตโนมัติในเบราว์เซอร์ (localStorage) ไม่ต้องกดเซฟเอง ปิด-เปิดเบราว์เซอร์ใหม่ข้อมูลยังอยู่

## วิธีใช้งาน

1. ดาวน์โหลดหรือ clone repository นี้
2. เปิดไฟล์ `index.html` ด้วยเบราว์เซอร์ (ดับเบิลคลิกได้เลย ไม่ต้องติดตั้งอะไรเพิ่ม)
3. กรอกฟอร์ม "เพิ่มอุปกรณ์ใหม่" ด้านบน แล้วกด "บันทึกอุปกรณ์" เพื่อเพิ่มรายการ
4. ใช้ช่องค้นหาและตัวกรองด้านบนตารางเพื่อหารายการที่ต้องการ หรือกดปุ่ม "แก้ไข"/"ลบ" ในแต่ละแถวเพื่อจัดการข้อมูล

## เทคโนโลยีที่ใช้

- HTML + CSS + JavaScript ล้วน ในไฟล์เดียว (`index.html`) ไม่มี framework ไม่มีไลบรารีภายนอก ไม่มี build tool
- `localStorage` สำหรับเก็บข้อมูลถาวรในเบราว์เซอร์ ไม่มีเซิร์ฟเวอร์และไม่มีฐานข้อมูล

## ข้อจำกัดที่ควรรู้

- **ข้อมูลเก็บอยู่ในเบราว์เซอร์เครื่องที่ใช้งานเท่านั้น** ไม่มีการซิงก์ข้ามเครื่องหรือข้ามเบราว์เซอร์ หากเปิดไฟล์เดียวกันจากเครื่องอื่นหรือเบราว์เซอร์อื่น จะไม่เห็นข้อมูลเดิม
- ถ้าล้างประวัติ/ข้อมูลเว็บไซต์ (clear cache/site data) ของเบราว์เซอร์ ข้อมูลทั้งหมดจะหายไปทันที เวอร์ชันนี้ยังไม่มีฟีเจอร์ส่งออก/นำเข้าเพื่อสำรองข้อมูล
- ไม่มีระบบผู้ใช้หลายคนหรือการล็อกอิน ใครก็ตามที่เปิดไฟล์นี้บนเครื่อง/โปรไฟล์เบราว์เซอร์เดียวกันจะเห็นและแก้ไขข้อมูลได้ทั้งหมด
- ยังไม่มีฟีเจอร์บันทึกประวัติการย้าย/เปลี่ยนผู้ถือครอง และยังไม่มีระบบแจ้งเตือนหมดประกันหรือข้อมูลไม่ถูกอัปเดต (ดูรายละเอียดขอบเขตทั้งหมดได้ที่ [SPEC.md](./SPEC.md))
